# Тема 1: Области видимости и Замыкания

1. **Затенение переменных:** Если внутри блока `{}` объявить переменную с тем же именем, что и снаружи, создается новая изолированная переменная. Внешняя не меняется.
2. **Объекты и массивы:** Копируются по ссылке (ведут на одну ячейку памяти). Чтобы сделать честную копию, используем spread-оператор: `const copy = { ...original };`.
3. **Замыкание (Closure):** Это способность функции помнить своё внешнее окружение (переменные), даже после того, как внешняя функция завершила работу.
4. **Ловушка var в цикле:** `var` создаёт одну переменную на всю функцию, поэтому функции внутри цикла запоминают только её последнее финальное значение. Использование `let` решает проблему, так как создаёт отдельную переменную на каждую итерацию цикла.

## Шпаргалка: Типы данных в JS (для повторения)
- **Примитивы** (String, Number, Boolean, null, undefined, Symbol, BigInt) — копируются **по значению** (создается независимая копия).
- **Объекты** (Object, Array, Function) — копируются **по ссылке** (ведут на один адрес в памяти).
- **Баг языка:** `typeof null` возвращает `"object"` — это официальная старейшая ошибка JS, которую оставили для обратной совместимости.
